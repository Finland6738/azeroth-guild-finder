# Interface previews

One image for every case of the Azeroth Guild Finder interface, so you can see what the addon looks like before you install it.

> **Design previews, not screenshots.** They are drawn from the addon's own layout and texts, in the look of the specification's mockups, with original emblems and banner art; the class icons are the game's own, loaded from the Wowhead CDN when the images are made and not stored in the repository. Nothing has been run in the WoW Forever client yet, so the real window may differ in small details (for example the banner pictures come from the game, and fonts are the game's own). Every image says so in its bottom strip.

The images are generated by `tools/make_mockups.py` (`python -X utf8 tools/make_mockups.py`): rerun it after a change of the interface. The scenes are in `tools/mockup_scenes.py` and `tools/mockup_scenes2.py`.

The addon has only an English interface for now, so there is no translated set.

Which images to upload to CurseForge, with titles and descriptions: [CURSEFORGE.md](CURSEFORGE.md).
