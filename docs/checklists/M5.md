# M5 in-game checks

Milestone M5 (Release) is not finished: this file collects the checks that only the real WoW Forever client can answer, one list per step, added as the steps are done. Nothing below has been run in the game.

## M5.1 — Settings page

Offline, the options, their defaults, their persistence across a reload and their effects are covered by `Tests/test_settings.lua`. What is left is how it looks and behaves in the real client. One character is enough; a Guild Master or an officer is needed for the Notifications card.

### Steps

- [ ] `/gf`, **Settings** (the first tab of the rail): the Window, Privacy and (for the Guild Master and officers) Notifications cards fit the page at 100 %, 60 % and 140 %, with no text cut or overlapping.
- [ ] Open the game's own settings (*Esc → Options → AddOns*): there is a **Guild Finder** entry showing the same cards. If the entry is **missing**, note it (`/gf debug`, Settings line: `game panel: unavailable`); that is allowed, the Settings tab must then have everything.
- [ ] Defaults on a fresh character (or after deleting the saved variables): minimap button on, notification icon on, *Only when something is pending* off, sound on, share alt count on, window size 100 %.
- [ ] *Show minimap button*: turning it off hides the button at once; `/gf` still opens the window; `/reload` keeps it hidden; turning it back on shows it again, also on another character of the account.
- [ ] *Window size*: each of 60, 80, 100, 120 and 140 % resizes the window at once; `/gf scale 80` moves the control; it is kept after `/reload`.
- [ ] *Share anonymous alt count*: off, then `/gf debug` Stats says sharing is off; on again.
- [ ] Guild Master or officer: *Notification icon on screen*, *Only when something is pending* and *Sound on new application* show and hide the icon, hide it while nothing is pending, and silence the sound; the same switches on the Applications tab and in the icon's right-click menu follow, and the Settings page follows them when changed there.
- [ ] A member or a player without a guild does not see the Notifications card.
- [ ] Drag the window and the notification icon away, then **Reset window position**: both come back; the options are unchanged.
- [ ] If the game's panel exists: change an option in the panel while the window's Settings tab is open (and the other way round): the other follows at once; the panel's **Defaults** button restores the options and the positions. Chat shows no Lua error.
- [ ] Every option is kept after `/reload` and after logging out and in.

If it works, tick the *In game* box of M5.1 in [M5-release.md](../roadmap/M5-release.md).

### What to report if it does not work

| Symptom | What it means | What to send |
|---|---|---|
| no Guild Finder entry in the game's settings | the client has no `Settings.RegisterCanvasLayoutCategory`, or registering raised | `/gf debug` (Settings line) and the Lua error, if any |
| the panel is empty or cut | the canvas size differs from the one assumed (540 x 640) | a screenshot, the window size of the game |
| an option does not stick | the saved value is repaired at login | `/gf debug` (Saved data section) |
| an option has no effect | the module that applies it did not run | the option, `/gf debug` |
