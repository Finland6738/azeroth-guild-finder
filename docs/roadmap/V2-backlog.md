# V2 backlog

Ideas for after `v1.0.0`. Each becomes a milestone file when it is planned.

| Idea | Notes |
|---|---|
| **Recommended guilds** | A "Suggested" view ranked by language, activity, schedule and new-player friendliness (decision D8) |
| **Raid progress and PvP statistics** | Aggregate only, from members' achievements or encounters, if the client exposes them (D12) |
| **Italian interface** | `Locale/itIT.lua`, then other languages (D22). The addon is ready since M5.3: every visible string is an `enUS` key (checked by `Tests/test_l10n.lua`), so a translation is one file listed in the TOC, with no code change |
| **Integration in Blizzard's windows** | A tab in the guild or social window, if technically compatible (D21) |
| **Signed listings** | Ed25519 signatures with a new protocol version, only if forged listings appear ([SPEC-02 §8](../specs/SPEC-02-network-protocol.md)) |
| **Application message** | A short optional text, if officers ask for it |
| **Founding date** | Only if a reliable source appears |
