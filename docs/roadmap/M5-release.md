# M5 — Release

**Goal:** a complete, polished, documented addon published on GitHub Releases and CurseForge.

**Exit criterion:** `v1.0.0` published on both, with the release checklist passed and the wiki up to date.

### M5.1 — Settings page
- Branch: `step/m5-1-settings`
- Spec: SPEC-04 §4
- Scope: Settings panel (`Settings.RegisterCanvasLayoutCategory`) and the Settings rail page: minimap button, notification icon and "only when pending", sound, anonymous alt count, scale, reset positions.
- Done when:
  - [x] Offline: one definition of the options (`UI/SettingsModel.lua`: minimap button, window size, anonymous alt count, notification icon, only when pending, sound; defaults taken from `Config.defaults` and equal to the wiki table) is drawn by one builder (`UI/SettingsPage.lua`) for both the Settings rail page and the panel in the game's Settings window (`Settings.RegisterCanvasLayoutCategory`, skipped with a note in `/gf debug` when the client lacks it); every option persists across a reload, applies at once (minimap button, window scale, Stats sharing, notification icon, Bus event), a damaged value falls back to its default, *Reset window position* puts back the window and the notification icon, the panel's Defaults button restores everything (`Tests/test_settings.lua`).
  - [ ] In game: the panel appears under *Options → AddOns* (or is absent without breaking anything), the page and the panel show the same values and follow each other, every option takes effect and is kept after `/reload` and a logout ([checklist](../checklists/M5.md)).

### M5.2 — Visual polish and accessibility
- Branch: `step/m5-2-polish`
- Scope: final nine-slice textures, shadows and grain; contrast check; tooltips on every icon; 1280 × 720 and scales 64–140 %; keyboard: Esc, Backspace for Back.
- Done when:
  - [x] Offline: the audits of `Tests/test_ui_polish.lua` pass. **Font size**: no style of the type scale under 12 px at scale 1.0, no font object made smaller (bundled or fallback), no `SetFont` outside `UI/Skin.lua` and `UI/Emblem.lua`. **Contrast**: every text/background pair of `Skin.TextPairs()` reaches WCAG 4.5:1 (7:1 for the main ink); text colours are tokens only. **Tooltips**: every button without a label, on every tab of every role and on the notification icon, menu and list, has one. **Keyboard**: Esc closes through `UISpecialFrames`; Backspace goes back, but never while an edit box has the keyboard. **Small screens**: the saved window and notification-icon positions are clamped onto the screen (`Nav.ClampPos`), and the book, rail and close button fit 1280 × 720 at every scale from 60 to 140 %. `tools/check_addon.py` checks the committed textures (the final shadow and gloss are generated by `tools/make_media.py`).
  - [ ] In game: the real window matches the design system, nine-slice textures, shadows and grain look right, no text under 12 px at 100 %, the window fits 1280 × 720 at 64–140 %, Esc and Backspace behave ([checklist](../checklists/M5.md)).
- Real client: the full visual comparison with the design system.

### M5.4 — Diagnostics
- Branch: `step/m5-4-diagnostics`
- Scope: `/gf debug` report (versions, capabilities, catalog size, sync state, last errors, listen-only reason) in a copy box, with no player names.
- Done when:
  - [x] Offline: `/gf debug` opens a structured report (`Core/Diagnostics.lua`, pure Lua: header with addon, client, interface and project versions; listen-only reason; last errors; then every debug section: capabilities, catalog size, sync state, role, settings, saved data, and so on) in a read-only multi-line copy box with *Select all* (`UI/DiagnosticsBox.lua`). A ring buffer keeps the last ten errors that name the addon (the game's error handler is wrapped, paths of the player's PC are removed). A test fails if a name of the mock roster or catalog, the character name or the realm appears (`Tests/test_diagnostics.lua`). The bug report form's debug field points to it.
  - [ ] In game: `/gf debug` opens the box, *Select all* + Ctrl+C copies the whole report, a real Lua error of the addon shows in *Last errors*, and the text pastes into the bug report form ([checklist](../checklists/M5.md)).
