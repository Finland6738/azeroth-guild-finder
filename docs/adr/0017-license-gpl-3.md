# 0017. Licence: GNU GPL v3.0

- Status: Accepted
- Date: 2026-11-08 (the owner's choice)

## Decision

The code and the documentation are released under the **GNU General Public License v3.0** (`LICENSE`), like azeroth-unspoken. Whoever modifies and redistributes the addon must publish their source under the same licence. Third-party parts keep their own licences: Ace3 and LibDBIcon (their own terms, embedded by the packager), Roboto and Roboto Mono (open font licences, with their licence file next to the fonts). Game textures are referenced by fileID and never redistributed.

## Consequences

- Positive: improvements stay open.
- Negative: closed-source forks are not allowed.
