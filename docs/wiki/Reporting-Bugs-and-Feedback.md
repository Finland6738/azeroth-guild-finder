# Reporting bugs and feedback

- **Ideas, questions, feedback**: the [Feedback discussions](https://github.com/Finland6738/azeroth-guild-finder/discussions/categories/feedback).
- **Bugs**: the [Bug report form](https://github.com/Finland6738/azeroth-guild-finder/issues/new/choose). Include the addon version, the game build and the output of `/gf debug`.
- **News**: the [Announcements](https://github.com/Finland6738/azeroth-guild-finder/discussions/categories/announcements).

Never paste other players' names, whispers, account names or folder paths from your PC.
