# Installation

> Available with the first release. Until then, follow the [Announcements](https://github.com/Finland6738/azeroth-guild-finder/discussions/categories/announcements).

1. Download the latest version from **CurseForge** or from the [GitHub Releases](https://github.com/Finland6738/azeroth-guild-finder/releases).
2. Close the game.
3. Extract the archive and copy the `AzerothGuildFinder` folder into `World of Warcraft/_forever_/Interface/AddOns/`.
4. Start the game and check that **Azeroth Guild Finder** is enabled in the AddOns list of the character screen.
5. In game, type `/gf` or click the minimap button.

## Updating

Replace the `AzerothGuildFinder` folder with the new one. Your saved data (the catalog, your application, your settings) is kept.

## The first time

The list of guilds fills over the first minutes, as the addon meets other players who use it. See [[FAQ|FAQ]].
