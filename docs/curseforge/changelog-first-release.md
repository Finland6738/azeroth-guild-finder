## Azeroth Guild Finder 0.9.0-beta.1

First public test version. It has been tested offline on a simulated client but **not yet in the real game**: please report anything that looks wrong.

- Find a Guild: search and filters (role, language, commitment, activities, play days and hours, members, requirements), always alphabetical.
- Guild page with the classes and roles wanted, schedule, honest statistics and requirements checked against your character.
- Apply with one click; My Application shows the status.
- Guild Masters: guided listing editor with live preview, emblem from the tabard or a designer.
- Officers: shared applications inbox (Invite, Decline, Whisper) and a movable notification icon.
- Peer to peer over a hidden channel: no server, no telemetry. Anonymous aggregate statistics, with an opt-out.
- Settings page, accessibility options, `/gf debug` diagnostics report.

Source and bug reports: https://github.com/Finland6738/azeroth-guild-finder
